# KARTO — Beyond Ordinary Potatoes

نظام واحد متكامل لمطعم KARTO: موقع الشركة + تطبيق الزبون (PWA بينزل على أندرويد وآيفون) + الكاشير POS + شاشة المطبخ + شاشة التلفزيون + لوحة المالك. كل الأجزاء بتشتغل على نفس قاعدة البيانات وبتتحدث مباشرة (Live).

## معاينة GitHub Pages

افتح [النسخة التجريبية](https://playmaxuzb.github.io/KARTO-NEW/) لمعاينة الموقع وتطبيق الزبون والكاشير والمطبخ وشاشة التلفزيون ولوحة المالك. هذه نسخة تفاعلية ببيانات تجريبية محفوظة في المتصفح، وليست نقطة استقبال طلبات حقيقية.

GitHub Pages يستضيف ملفات الواجهة فقط. لتشغيل النظام الفعلي بخادم وقاعدة بيانات، انشر المشروع كخدمة Docker مع تخزين دائم للمجلد `/data` واضبط `OWNER_PIN` قبل استقبال الطلبات.

## الروابط داخل النظام
| الرابط | لمين | شو فيه |
|---|---|---|
| `/` | الزبائن | موقع الشركة (3 لغات) |
| `/app` | الزبائن | تطبيق الطلب: الحجم، طريقة التقديم، حتى 3 نكهات، صوصات، مشروبات، سلة، توصيل/استلام، تتبع، فاتورة إلكترونية، نقاط |
| `/staff` | الموظفين | تسجيل دخول بالـ PIN |
| `/staff/pos` | الكاشير | الكاشير: طلبات المحل، حساب الباقي، فواتير متسلسلة، قبول الطلبات الأونلاين، فتح وإغلاق الوردية |
| `/staff/kds` | المطبخ | شاشة المطبخ: جديد ← قيد التحضير ← جاهز، مع تنبيه صوتي وتأخير بالأحمر |
| `/staff/tv` | شاشة المحل | منيو + أرقام الطلبات (قيد التحضير / جاهز) — بدون بيانات شخصية |
| `/admin` | المالك والمدير | لوحة الأرباح، البحث بالفواتير، تعديل المنيو والأسعار، المخزون، المصاريف، الموظفين، سجل التدقيق، وضع الصيانة |

## أرقام PIN التجريبية (غيّرها فوراً من /admin/staff)
- المالك: `1111` (أو حط `OWNER_PIN` قبل أول تشغيل) · المدير: `2222` · الكاشير: `3333` · المطبخ: `4444`

## التشغيل على جهازك
يحتاج Node.js نسخة 22.13 أو أحدث.
```
npm run setup
npm run build
npm start
```
بعدين افتح `http://localhost:4000`.

## النشر على الإنترنت (سيرفر)
أسهل طريقة: سيرفر VPS (مثلاً 5–10$ بالشهر) أو خدمة مثل Render / Railway / Fly.io باستخدام الـ Dockerfile:
```
docker build -t karto .
docker run -d -p 80:4000 -v karto-data:/data -e OWNER_PIN=xxxx karto
```
- لازم يكون في **HTTPS** (دومين مثل karto.uz + شهادة SSL مجانية من Let's Encrypt / Cloudflare). بدونه ما بيشتغل تثبيت التطبيق على الموبايل.
- قاعدة البيانات ملف واحد: `/data/karto.db` — اعمل نسخة احتياطية يومية منه.

## تثبيت التطبيق على الموبايل
بعد النشر على HTTPS: الزبون بيفتح `karto.uz/app` ← "إضافة إلى الشاشة الرئيسية" (آيفون) أو "تثبيت التطبيق" (أندرويد). بيطلع بأيقونة KARTO وبيفتح كتطبيق كامل.
للنشر على App Store و Google Play: بنغلّف نفس التطبيق (Capacitor) — بدك حساب Apple Developer (99$/سنة) وGoogle Play (25$ مرة وحدة).

## شو لسا بدّه حساباتك الرسمية
1. **الدفع الأونلاين Click / Payme / Uzcard / Humo:** النظام بيسجّل طريقة الدفع وحالتها؛ الربط الفعلي بدّه حساب تاجر (merchant) عندهم.
2. **الفاتورة الضريبية الرسمية:** الفواتير هون متسلسلة (KARTO-000001) ومحفوظة بسجل تدقيق، بس الإيصال الضريبي الرسمي بدّه ربط مع كاش أونلاين/فيرتشوال كاشير معتمد بأوزبكستان (قرار مجلس الوزراء 943).
3. **Yandex Eats / Uzum Tezkor:** بتسجّل كمطعم شريك عندهم؛ طلباتهم بتوصلك على جهازهم.
4. **SMS:** للتأكيد برسالة بدّه مزوّد SMS محلي (Eskiz / Play Mobile).

## التعريفات المحاسبية (كما بلوحة المالك)
- صافي المبيعات = المبيعات − الخصومات (الملغي والمسترد مستثنى)
- COGS = استهلاك المكونات حسب الوصفة × سعر الوحدة بالمخزون (بيتخصم تلقائياً لما الطلب يكتمل)
- الربح الإجمالي = صافي المبيعات − COGS
- صافي الربح = الربح الإجمالي − المصاريف المسجلة − الرواتب المستحقة (الراتب الشهري ÷ 30 × عدد أيام الفترة)
- الأسعار والأوزان والتكاليف الحالية **تجريبية** — عدّلها من `/admin/menu` و `/admin/stock` بعد عروض الموردين وتجربة الوصفة، وراجع الضرائب مع محاسب.

## البنية التقنية
- `server/` — Node.js + Express + SQLite (مدمج بـ Node، بدون برامج إضافية). صلاحيات حسب الدور، PIN مشفّر (scrypt)، سجل تدقيق لكل تعديل، الأسعار بتنحسب بالسيرفر (ما حدا بيقدر يغيّرها من المتصفح)، حد لعدد الطلبات.
- `web/` — React + Vite + Motion. نفس التصميم والهوية بكل الشاشات.
- الصور: `web/public/img` (الصور المعتمدة اللي عليها شعار KARTO).
